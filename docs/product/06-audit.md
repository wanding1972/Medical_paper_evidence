## 审计发现与已修复项

1. 复核 HTTP JSON array 与 strict tuple DTO 不兼容：独立 HTTP DTO，域内不可变集合；端到端复核通过。
2. 参考文献失焦重绘清空 PDF 绑定：保留仍有效绑定，真实浏览器回归覆盖。
3. 解密正文临时文件与 multipart 默认磁盘溢写：正文/受限上传均内存处理，显式配置 parser spool 上限；超过默认1MiB的上传测试验证未 roll 到磁盘。
4. 摘要标题与正文同段未被排除：配置标题边界，摘要不进入 EvidenceSpan；真实 PDF 用例覆盖。
5. 只验证总体关系可能升级未知限定项：配置增加各关系 unknown 计数，保守降级；不涉及数值/效果方向有显式 not_applicable，不强迫伪造“相同”。
6. 可移除语义计数器导致配置/执行错配：加载时完整性校验；错误操作数/字段/重复触发/正则/限额类型检查。
7. 跨文件相同坐标可能复用旧 Evidence ID：ID 纳入实际原 PDF SHA256；旧观察在更换文件后被拒绝。
8. 仅用户 consent 可能混淆全局关闭策略：产品 model.enabled 默认 false；配置开启和每任务同意缺一不可。
9. BM25 在候选循环重复计算文档频率：一次计算，避免平方级候选遍历。
10. 长任务/停机缺少预算：PDF 每页、模型调用和最终输出检查配置时间预算；停机保留未完成任务以便重启恢复。
11. 模型或解析失败诊断不足：加密保存步骤耗时、输入/规则哈希、模型/提示词版本和失败诊断；原始响应仅加密保存，不返回普通报告、不写日志。
12. 盲测可能把缺样本/零预测当通过：独立评测工具拒绝模板/未确认/集合泄漏/缺预测；precision 无定义为 null，门槛不能通过。

当前实现范围未修复 fail：0。初步PII扫描不是匿名化证明；跨语言召回和语义候选效果需要真实盲测，不纳入“测试通过”的虚假结论。

## 验收边界与剩余外部前提

| 项目 | 当前状态 | 完成所需 |
|---|---|---|
| 单机软件工作流 | 实现并本地端到端验证 | 参照README启动即可内部试用 |
| 外部模型 | 适配器/Schema/失败与同意门禁已测；未真实联调 | 安全配置指定供应商HTTPS地址、模型名和密钥；允许对应网络域，再运行真实联调 |
| 医学精度 | 未验收 | 已授权的真实正文与PDF、人工确认/仲裁金标、独立盲测清单；运行评测工具并审查错误 |
| 生产隐私/安全/版权 | 未验收 | 专家审查PII漏检、存储/密钥管理、公开服务TLS/访问控制及依赖/文献许可 |
| 用户价值/收费 | 未验证 | PRD要求的真实用户试用与付费意愿验证；不凭代码模拟用户或收入 |

因此本轮交付是可运行的单机产品工作流与验收工具；不是完成医学验证、获得生产批准或已发布的付费SaaS。剩余真实资料与第三方服务条件不能通过生成虚构样本或绕过门槛补足。
