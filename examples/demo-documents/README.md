# 可上传的演示材料（非真实医学研究）

这些文件是本项目生成的非临床合成测试材料，可用于软件演示，不是医学金标或真实证据。Word 仅含普通标题和段落，没有表格、图片、文本框、修订或脚注。

## 推荐先试 01

1. 正文上传 `01-cited-chapter.docx`。
2. 语言选择 `en-en`（英文正文/英文证据）。
3. 参考文献框粘贴 `references.txt` 中的一行。
4. 证据上传 `reference-1-synthetic.pdf`，绑定编号1。
5. 保持外部模型关闭，确认仅对这些合成材料有处理权限，提交。
6. 应能看到候选论断和带页码的证据；未进行人工比对时仍为“尚未核验”，不是自动判为支持。

## 其他两个用例

- `02-missing-citation.docx`：不填参考文献、不上传PDF。应显示 `missing_citation`（缺少引用）。
- `03-unresolved-reference.docx`：参考文献仍只填写编号1，可上传同一个PDF并绑定1。正文引2，应显示 `unresolved_reference`（引用号无法映射），不能越界检索文献1。

所有用例均应完成任务并给出审计结果，不应触发 unsupported_docx_structure。出现 Warning/Error 是演示预期，不代表任务运行失败。

真实使用应提交医学论文引言或讨论中的一个章节及其已引全文；DevOps RFP 不在当前医学规则适用范围内。真实 Word 不能仅因删除图片或表格就假定内容已被完整提取，转换后须核对原文。
